CAIRN Fusion 0.6.6 — Installation Requirements

REQUIRED
- Windows 10 or Windows 11
- Python 3.11 or newer
- Python pip and venv support
- Chrome, Brave, or Microsoft Edge for the browser extension

OPTIONAL
- Obsidian (CAIRN can read/write the Markdown vault without Obsidian running)
- Ollama + local model (only for optional Agent AI assistance)

SETUP
Run scripts\setup_windows.bat. It checks Python/version, pip, venv, installs requirements, verifies imports, and runs the automated tests. If something required is missing, setup stops and tells you what to install/repair.

CAIRN Help

Fusion Preview 0.6.3 · Tutorial + troubleshooting

Bridge · Web/AI → Vault

Selection: highlight text and click Save to CAIRN.

Long conversations: click the green Save Chat button or use the extension popup → Save Complete Chat. No highlighting required.

You can then Save to Inbox, Create New Note, Append Existing, Add Under Heading, or Patch Heading Body.

Brain · Vault → Chat

Click CAIRN Brain, choose exact .md notes, then Insert into Chat. You can also type [Note.md] and resolve it explicitly.

Open .md shows the raw Markdown. Attach .md attempts to attach the Markdown file to the current AI chat; if the site blocks programmatic attachment, use Download .md or Insert into Chat.

Agent

Talk naturally. Examples: show history, find notes about SVM, what is in [Chapter 2.md]?, list notes, status, doctor, undo last.

CAIRN first uses deterministic/index-backed logic. If Ollama is already running with Qwen/Gemma/Llama/etc., it may synthesize grounded answers from indexed vault search results.

Context Spaces

Brain → select exact notes → Save Space → name the Space inside the CAIRN panel. Later choose it from Context Spaces and click Load. No whole-page refresh is required.

Setup requirements

Required: Windows 10/11, Python 3.11+ with pip + venv, and Chrome/Brave/Edge for the browser extension. Optional: Obsidian for its UI/deep links and Ollama for local AI assistance.

scripts\setup_windows.bat now checks Python version and verifies required Python packages after installation.

When something goes wrong

Bridge: confirm CAIRN.bat is running, copy the current token again, then Test Connection. Stale notes/spaces: Brain → ↻. Write conflict: reopen the target and retry; CAIRN intentionally did not overwrite the newer version.

Claude attachment: open Claude's attachment control once, then retry Attach .md if Claude has not exposed its uploader yet.

Safety

Markdown remains the source of truth. SQLite is a rebuildable index/history layer. Writes use hash conflict checks, atomic replacement, and Undo snapshots.

If something looks wrong, run Doctor and test on a copy of important notes first.
